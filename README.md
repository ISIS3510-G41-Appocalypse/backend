# Happy Ride Backend API Docs

## Description
Swagger documentation for the Happy Ride backend API.

## Structure
- `docs/index.html`: Swagger UI
- `docs/openapi.json`: OpenAPI specification exported from Supabase/Postman

## Run locally
Open `docs/index.html` with Live Server or any static server.

## Deploy
This project can be deployed with GitHub Pages or Vercel.
